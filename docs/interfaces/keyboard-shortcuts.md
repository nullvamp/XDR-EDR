# Keyboard shortcuts

| Shortcut | Result |
|---|---|
| `Ctrl+K` / `Cmd+K` | Open bounded quick navigation; no destructive commands |
| `/` | Focus global search when not editing a control |
| `Escape` | Close the command palette |
| `J` / `Down Arrow` | Move to the next linked table row |
| `K` / `Up Arrow` | Move to the previous linked table row |
| `Enter` on a row | Open its primary object |
| `Enter` / `Space` on a table header | Sort the currently loaded page |
| `Previous alert` / `Next alert` | Move through the current loaded alert page without losing queue filters |
| `Focus selected subtree` | Limit a loaded process tree to the keyboard-focused node and its descendants |
| `Reset view` | Restore all loaded process-tree nodes and clear the local filter |
| `Tab` / `Shift+Tab` | Traverse all controls using native browser order |

Browser and assistive-technology conventions take precedence: single-key shortcuts do not fire while focus is in an input, text area, or select. Destructive actions are deliberately absent from quick navigation and retain normal confirmation and approval.
