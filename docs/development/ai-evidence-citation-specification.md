# AI evidence and citation specification

`ai-evidence-package.v1` is the only provider input authority. A package binds tenant, context type/ID, creator, policy version/hash, deterministic package ID/hash, ordered items and an explicit truncation report. Candidate selection is application-owned and follows exact alert/incident membership, finding authority, bounded entity graph traversal, IOC/tunnel identity, forensic collection identity and related response action identity.

Each item records stable `[EVID-NNNN]`, evidence UUID, type/source/time, tenant, endpoint/entity identity where available, provenance, bounded confidence/ambiguity, source reference and allowlisted structured fields. Ordering is observation time then stable evidence ID. Bounds are enforced before provider access: 200 hard items, 1 MiB hard serialized bytes, tenant policy item/byte limit, conservative serialized-character context-token budget, field count/length, graph depth/nodes/edges and per-domain selection caps. Omission records count, bytes and the exact limiting reason; it is never silent.

Material `Observed`, `Derived`, `Inference`, and `Ambiguous` claims require declared citations. `Unknown` may be uncited only when it states absence/insufficiency. Validation rejects nonexistent, foreign/out-of-package, duplicate, undeclared embedded or missing citations, active content, and non-read-only output. Citation resolution repeats tenant authorization and returns the exact included item, timestamp, source, endpoint/entity, provenance, reference and fields.

Evidence values are untrusted data. Keys/values are plain-text bounded, secrets are replaced with `[REDACTED_SECRET]`, configured personal identifiers are irreversibly hashed, and instructions embedded in filenames, command lines, DNS, forensic text, notes, HTML or JSON never enter the policy channel. Structured forensic citations retain collection/item IDs, source object, acquisition method/tool version, hash, race/truncation/quality/failure state and artifact reference; large binary bytes are never placed in context.
