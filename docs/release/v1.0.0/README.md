# Open Security Platform 1.0.0 release documentation

This is the frozen documentation set for the Windows-first v1 engineering release candidate. The qualification boundary is Windows 11 Enterprise build 26200 on x64 in the authorized Hyper-V victim VM, with the single-host Compose deployment used as a development and qualification topology. It is not unrestricted production certification.

Use `installation.md` and `deployment.md` for deployment; `upgrade-rollback.md`, `uninstall-decommission.md`, and `troubleshooting.md` for lifecycle operations; `security.md` and `administrator-guide.md` for governance; `analyst-guide.md` and `dfir-guide.md` for SOC work; and `backup-restore.md` plus `disaster-recovery.md` for recovery.

The normative limitations and capability classifications are `known-limitations.md` and `windows-support-matrix.md`. Architecture details remain in `docs/architecture`, security and operational ADRs in `docs/adr`, and exact Sprint evidence in `docs/development`.
