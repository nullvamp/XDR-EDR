# DFIR guide

Create/select a case, identify the exact endpoint installation and time window, request Quick Triage or an approved targeted collection, and monitor resumable transfer state. Large artifacts are chunked, bounded, backpressured and hash-verified; they are not constrained to a small interactive-shell response. Tools must be allow-listed, hash-bound, size/timeout limited and explicitly authorized.

The forensic workspace provides case evidence, collection jobs, evidence browser, metadata, parsers, notes, relationships, export and chain-of-custody views. Preserve source, acquisition time, endpoint/installation identity, native file identity where available, SHA-256, object ID, parser/version, analyst actions and audit references.

Packet payloads and arbitrary memory contents are not collected by the current sources. Kernel-only prevention and some source-specific lifecycle facts are not observable. Never claim an inferred fact as native evidence. Exported evidence must be re-hashed and handled under organizational legal/privacy/retention policy.
